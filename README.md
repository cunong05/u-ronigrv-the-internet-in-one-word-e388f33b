# The Internet in One Word

One word for the whole internet:

**enshittification**

Why this word wins:

- **Funny** — it is a gloriously blunt, made-up-sounding word that lands like a punchline.
- **True** — it names the exact arc of the modern internet: platforms that start great for users, then get worse as they squeeze value for everyone else. Everyone who has lived online has felt it.
- **Surprising** — it is not the first obvious word ("connection", "cat", "meme"). It is a sharp, unexpected pick that still fits the whole internet perfectly.

## Run it

```sh
node --experimental-strip-types main.ts
```

This writes the entry word to `/output/entry.txt` (UTF-8, no trailing newline).
